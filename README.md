# 🎵 Rhema 
![image](https://github.com/user-attachments/assets/baac6342-38a6-4952-96e1-e51b44684036)

예배 때마다 사용되는 찬양들을 등록하고 관리하고 공유하는 서비스

<br>

## ❔ 개발하게 된 목적
지금 교회에서 찬양팀으로 봉사하고 있는데 매주 예배때 부르게 될 찬양을 서로 카톡방을 통해 공유합니다. <p>
이전에 이미 했던 곡들인 경우에도 새로 악보 파일을 올리고 새로 폼을 작성해야하는 것이 번거롭다 생각되어 어플을 통해 관리를 하면 어떨까? 라는 생각해 개발을 시작하게 되었습니다. <p>
현재 목표는 저희 찬양팀 내에서 사용하는 것을 시작으로 하여 잘 활용함으로써 다른 부서들도 사용하게 하는 것입니다.

<br>

## ✔️ 주 기능
- 찬양 이름, 코드, 악보 이미지 등의 곡 정보를 작성하여 등록 및 관리 기능
- 찬양 이름별, 코드별, 날짜별 검색 기능
- 예배 때 사용될 콘티(찬양 리스트) 작성 및 관리 기능 <p>

**➕ 추가 예정 기능**
- 찬양팀 내 채팅 기능
- 악보 이미지에 그림판 기능 제공

<br>

## 📁 프로젝트 환경
- Java
- SpringBoot
- Gradle
- PostgreSQL
- JPA
- S3
- AWS EC2

<br>

## 🌳 브랜치 관리
- main : 실제 배포 때 사용될 브랜치
- develop : 개발 브랜치
  - 기능 브랜치 : domain 별로 브랜치를 나눠서 개발하기로 하였고, 해당 도메인의 기능이 완성되면 develop 브랜치에 push
